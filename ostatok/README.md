# Остаток

Прототип приложения для учёта расходов с накопительным дневным бюджетом.

## Как запустить

Открыть `index.html` двойным кликом — это один самодостаточный файл,
сборка и зависимости не нужны.

## Логика расчёта

```
свободный доход = доход − обязательные расходы − накопления
бюджет на день  = свободный доход / число дней в периоде
остаток сегодня = остаток вчера + бюджет на день − траты за сегодня
```

Ключевое отличие от обычных трекеров: остаток **не обнуляется** каждый день.
Он накапливается, если тратить меньше нормы, и уходит в минус, если больше —
и постепенно выправляется сам.

Период задаётся произвольно (обычно от зарплаты до зарплаты),
не привязан к календарному месяцу.

## Что работает в прототипе

- Вход: Apple и почта с одноразовым кодом
- Онбординг из трёх шагов: период → доход и обязательные расходы → расчёт бюджета
- Экран «Сегодня»: доступная сумма, состав остатка, список трат
- Добавление траты: клавиатура, живой пересчёт, быстрые подсказки описания
- Удаление траты с возможностью отменить действие
- История по периодам: график остатка, календарь трат, список дней
- Архив всех периодов с переходом внутрь

Данные хранятся в памяти страницы — при перезагрузке сбрасываются.
Все суммы в демо вымышленные.

## Что дальше

Для рабочей версии нужен бэкенд с разделением данных по аккаунтам:
таблицы `users`, `periods`, `mandatory_expenses`, `transactions`,
авторизация по одноразовому коду, изоляция строк по владельцу.
